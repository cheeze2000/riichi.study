# Setting up the game

After gathering four people and the equipment, you need to do a few things before you can start playing.

## Confirming rules

Riichi mahjong has many rule variations.
Make sure everyone agrees on the rules before starting.

For example, in online clients, the game ends when someone's points go into the negative.
However, in real life, the game usually continues.

## Preparing tiles

Make sure you are playing with the standard 136 tiles.
If your mahjong set has **flower** or **season** tiles, be sure to set them aside.

You can also swap the "normal five" tiles with "red five" tiles if your set has them.

Players typically start the game with **25,000** points.
There are two known combinations used to distribute these points.

| Value | Combination 1 | Combination 2 |
| :---: | :---: | :---: |
| 10,000 | 1x | - |
| 5,000 | 2x | 3x |
| 1,000 | 4x | 8x |
| 500 | 1x | 3x |
| 100 | 5x | 5x |

> [!NOTE]
> Some automatic mahjong tables also feature **black** sticks.
> They are worth 10,000 points and are used to track negative points.

## Determining player order

There are several ways to decide the seating arrangement.

The most common method is to shuffle the four wind tiles face-down and have everyone pick one.
The player who draws East picks their seat, and then the remaining players sit accordingly.
