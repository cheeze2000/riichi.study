# Hand value

This section explains how **yaku** and **dora** contribute to the value of your hand.

Hand value is measured in **han** and **fu**.

> [!NOTE]
> **Fu** is explained in the more advanced sections.

## Han from yaku

Every **yaku** has a value in terms of **han**.
For example, **riichi** is 1 **han**.
Full flush (chinitsu) is a whopping 6 **han**.

Some **yaku** have reduced value in open hands.
Full flush is only worth 5 **han** in open hands.

## Han from dora

**Dora** tiles give an extra 1 **han**.
However, you have learned previously that **dora** can stack on the same tile. In that case, a double **dora** tile would be worth 2 **han**.

> [!WARNING]
> Dora is **not** a yaku!

## Example

Dora indicator: `mj 00z7m0000z`

```mj
055m22067p45s _ 6s _ 8-88m
```

This hand is worth 6 **han**:
- All simples (1 **han**)
- Dora (3 **han**) from `mj 8m`
- Aka dora (2 **han**) from `mj 0m` and `mj 0p`

## Points

The table shows estimates of hand value given the total **han** in the hand.

| Han | Points |
| --- | --- |
| 1 | 1,000 - 2,000 |
| 2 | 2,000 - 4,000 |
| 3 | 4,000 - 8,000 |
| 4, 5 | 8,000 |
| 6, 7 | 12,000 |
| 8, 9, 10 | 16,000 |
| 11, 12 | 24,000 |
| 13+ | 32,000 |

## Hand value as a dealer

As the **dealer** (East), hands are worth 50% more.
For example, a hand worth 1,000 points as a **non-dealer** is worth 1,500 points as a **dealer**.

However, if a player wins by **tsumo**, a **dealer** pays double the amount of the other players.
For example, if a **non-dealer** wins an 8,000-point hand by **tsumo**, the other **non-dealers** pay 2,000 while the **dealer** pays 4,000.
