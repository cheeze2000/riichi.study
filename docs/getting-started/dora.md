# Dora

**Dora** are tiles that give bonus values to your hand.

## The dora indicator

At the start of every hand, one **dora indicator** is shown.

```mj
00z3p0000z
```

The tile **after** the **dora indicator** is the **dora**.
This means `mj 4p` is the **dora**.

Numbers follow this ordering:
```mj
123456789s
```

Winds follow this ordering:
```mj
1234z
```

Dragons follow this ordering:
```mj
567z
```

Here are some examples of **dora** given their **dora indicators**.

| Dora indicator | Dora |
| :---: | :---: |
| `mj 7m` | `mj 8m` |
| `mj 1p` | `mj 2p` |
| `mj 9s` | `mj 1s` |
| `mj 2z` | `mj 3z` |
| `mj 4z` | `mj 1z` |
| `mj 5z` | `mj 6z` |
| `mj 7z` | `mj 5z` |

## Aka dora

**Aka dora** are "red five" tiles that are used in some rulesets.

```mj
0m _ 0p _ 0s
```

**Dora** bonuses can stack on the same tile. If the **dora indicator** is `mj 4s`, `mj 0s` is double **dora**.

## Additional dora

During gameplay, additional **dora** can be introduced in a hand.

### Kan dora

Whenever a player calls **kan**, a new **dora indicator** is revealed.

```mj
00z3p9m000z
```

Now, both `mj 4p` and `mj 1m` are the **dora** for the current hand.

### Ura dora

Upon winning after declaring **riichi**, tiles underneath the current **dora indicator(s)** become additional **dora indicators**.

This effectively doubles the number of **dora indicators**. As a result, **ura dora** can greatly increase the value of hands won with **riichi**.
